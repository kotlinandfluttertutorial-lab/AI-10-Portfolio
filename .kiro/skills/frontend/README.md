# Skill: Frontend Engineering

This skill covers frontend development with React and TypeScript.

## Topics
- React + TypeScript project setup (Vite or Create React App)
- Component architecture (functional components, hooks)
- State management (React Query for server state, Zustand or Context for UI state)
- API client patterns (typed fetch wrappers, error handling)
- Form validation and error display
- Authentication UI (login, token management, session handling)
- Accessibility (WCAG 2.1 AA, keyboard navigation, ARIA)
- Responsive layouts
- ESLint + Prettier configuration
- Jest / Vitest + React Testing Library
- Playwright for end-to-end tests
- Environment variable handling (VITE_* or REACT_APP_*)
- Build and deployment configuration
