# Skill: AI Agents

This skill covers agentic AI patterns used in P02, P04, P07, and P09.

## Topics
- Agent planning and task decomposition
- Tool definition and allowlisting
- Tool call validation and authorization
- Multi-step execution loops with iteration limits
- State management across agent steps
- Shared state between multiple agents
- Agent dependency graphs
- Human approval gates for external side effects
- Bounded retries and cost budgets per session
- Agent trace collection (OpenTelemetry compatible)
- Agent evaluation: task completion rate, plan validity
- Prompt injection defense in agentic contexts
- LangChain / LangGraph / custom agent frameworks
- ReAct pattern implementation
