# Skill: Architecture

This skill covers software architecture patterns used across all 10 projects.

## Topics
- Modular architecture with domain/API/adapter separation
- Provider abstraction patterns (LLM, embedding, STT, vision)
- Database boundary design (pgvector, migrations, soft deletes)
- Async processing with message queues
- Event-driven architecture
- Error handling and circuit breakers
- Observability (logs, metrics, traces, health endpoints)
- Horizontal scalability patterns
- Security boundary design
- Architecture Decision Records (ADRs)
