# Skill: Testing

This skill covers test design and implementation for all 10 projects.

## Topics
- pytest configuration and project structure
- Unit test patterns with unittest.mock and pytest-mock
- Integration test patterns with testcontainers or pytest-docker
- FastAPI TestClient for API testing
- schemathesis for OpenAPI contract testing
- Security test patterns (auth, authorization, injection)
- Performance testing with locust or k6
- pytest-benchmark for micro-benchmarks
- Playwright for end-to-end UI tests
- Test fixture design (factories, database seeds)
- Test reporting (pytest-html, pytest-json-report)
- CI test pipeline configuration (GitHub Actions)
- Coverage reporting with pytest-cov
- Regression test management
