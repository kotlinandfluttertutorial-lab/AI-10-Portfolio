# Skill: Backend Engineering

This skill covers backend development patterns for Python/FastAPI services.

## Topics
- FastAPI application structure (routers, dependencies, middleware)
- Pydantic models for request/response validation
- SQLAlchemy ORM with Alembic migrations
- Async database operations with asyncpg
- Background task queues (Redis Streams, Celery)
- API versioning (/v1/ prefix)
- Consistent error envelope design
- Authentication middleware (JWT, API keys)
- Rate limiting with Redis
- Health and readiness endpoints
- Structured JSON logging
- Prometheus metrics exposition
- Docker and docker-compose setup
- Environment variable configuration patterns
