# Skill: RAG (Retrieval-Augmented Generation)

This skill covers building RAG systems for P01 and related retrieval work in P03 and P08.

## Topics
- Document ingestion pipelines (PDF, DOCX, plain text)
- Text parsing and cleaning
- Chunking strategies (fixed-size, sentence-aware, semantic)
- Embedding generation and model versioning
- Vector database storage (pgvector, Pinecone, Weaviate)
- Keyword search (BM25, full-text search)
- Hybrid retrieval (keyword + semantic)
- Reranking (cross-encoder, Cohere Rerank)
- Context assembly and prompt construction
- Grounded answer generation with citations
- Citation verification and precision measurement
- RAG evaluation: Recall@k, MRR, faithfulness, answer relevance
- Stale index detection and re-indexing strategies
- Multi-tenant document isolation
