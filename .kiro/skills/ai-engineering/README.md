# Skill: AI Engineering

This skill covers patterns for building reliable, production-quality AI integrations.

## Topics
- LLM provider abstraction (OpenAI, Anthropic, Azure OpenAI)
- Prompt template design and versioning
- Structured output parsing and validation
- Token budget management and cost tracking
- Retry with exponential backoff
- Fallback strategies on provider failure
- Streaming responses
- Model selection and configuration
- LLM evaluation frameworks (RAGAS, custom metrics)
- Prompt injection defense
- AI output validation before use
- Logging AI interactions without exposing sensitive payloads
- Human-in-the-loop review gates for high-stakes outputs
