# Product Steering

Build AI Pull Request Review and Quality Assistant for Software developers, maintainers, engineering teams, repository administrators. The core problem is: Reviewers need contextual, actionable feedback on pull requests without noisy comments, secret exposure, or unsafe automated changes.

Prioritize a usable, safe end-to-end workflow over broad feature count. Keep AI outputs reviewable, evidence-aware, and measurable. Avoid claims of production readiness without test evidence.
