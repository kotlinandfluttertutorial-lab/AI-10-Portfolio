Start here:
1. Read `PROJECT-SPEC.md`.
2. Review `specs/requirements.md` and `specs/design.md`.
3. Import `jira/P07-tickets.csv` into Jira after mapping fields.
4. Open the matching prompt in `kiro-prompts/` for each ticket.
5. Use `.kiro/steering/` and `.kiro/specs/` as the initial Kiro project guidance.
